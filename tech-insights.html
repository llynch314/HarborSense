Top 10 Technical Skills Learned

1. Website Development Life Cycle (SDLC)

During this project, we learned how professional websites are developed through multiple stages including planning, design, development, testing, launch, and maintenance. We applied this process by first identifying the goals of HarborSense, researching our audience, creating wireframes, building pages, testing features, and continuously improving the site based on feedback.

2. Semantic HTML5 Structure

We used semantic HTML5 elements such as <header>, <nav>, <main>, <section>, and <footer> to organize content properly. These tags improve readability, accessibility, and search engine optimization while creating a cleaner and more professional website structure.

3. Responsive Web Design

We learned how to create layouts that adapt to different screen sizes using responsive design techniques. This included flexible layouts, scalable images, and viewport settings so the HarborSense website works effectively on desktops, tablets, and phones.

4. CSS Styling and Visual Effects

Through CSS3, we learned how to improve the visual appearance of a website using colors, spacing, rounded corners, shadows, hover effects, and consistent typography. These styles helped create a modern design that matched the environmental theme of HarborSense.

5. Advanced Form Design

We learned how to create user-friendly forms using HTML5 form elements and attributes. This included using input types such as email fields, placeholders, required fields, and organized layouts to improve usability. These techniques helped us create surveys and contact forms that were easier for users to complete accurately.

6. Testing and Validation

We learned the importance of testing websites across multiple browsers and devices to ensure compatibility. We also used HTML and CSS validation techniques to identify and correct coding errors, improving the reliability and professionalism of the site.

7. Accessibility Principles

Accessibility was an important part of development. We practiced using descriptive alt text for images, readable font sizes, proper color contrast, and organized navigation structures so the website could be used by a wider audience.

8. File Management and Organization

We learned how to organize website files into a structured system including separate folders for images, stylesheets, and webpages. This made the project easier to maintain and allowed links and media to function correctly throughout the site.

9. User Interface and Design Principles

We applied design principles such as alignment, contrast, repetition, and proximity to improve readability and visual consistency. We also learned how layout and spacing affect the user experience and help visitors navigate information more efficiently.

10. Writing and Organizing Content for the Web

We learned how to structure online content using headings, paragraphs, tables, bullet points, and concise writing styles. Organizing information clearly helped users quickly understand the purpose of HarborSense and explore different sections of the website more easily.
